## Download the transcripts

```bash
./yt-transcribe --lang en --out mit-6.006 \
  "https://www.youtube.com/watch?v=6FkRvTtUc-o&list=PLUl4u3cNGP63URZnh5iqBzDTDYPUTQT-8"
```

This creates 15 `.vtt` files in the `mit-6.006/` directory.
