# Contributing

Thanks for considering contributing!

## Before submitting a PR

- Run `shellcheck transcribe_playlist.sh` and fix any warnings.
- Test the script against at least one real playlist.
- Keep changes focused — one PR per feature or fix.

## Reporting issues

- Use the [bug report](.github/ISSUE_TEMPLATE/bug_report.md) or [feature request](.github/ISSUE_TEMPLATE/feature_request.md) templates.
- Include the full command output and your OS/yt-dlp version.
