# Contributing

## Before submitting a PR

- Run `go vet ./...` and fix any warnings.
- Run `go build -o yt-transcribe .` and verify it compiles.
- Test against a real playlist.
- Keep changes focused — one PR per feature or fix.

## Reporting issues

Use the [bug report](.github/ISSUE_TEMPLATE/bug_report.md) or [feature request](.github/ISSUE_TEMPLATE/feature_request.md) templates. Include the full command output and your OS/Go version.
